# Purrfectly Groomed

A ServiceNow Service Portal application for a pet grooming business, built as the 
capstone project for the NextGen ServiceNow training program (Apr–Jun 2024).

## What It Does

Purrfectly Groomed lets pet owners:
- Browse and request grooming services through a Service Catalog
- Track grooming appointments in real time via a Pet Grooming Time Tracker
- Search a Knowledge Base for pet care articles
- Leave reviews for completed services

![Service Portal Home](.image/service-portal-home.png)
